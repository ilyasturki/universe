When a game won't start or misbehaves, run System check first, then read the game's log. [Game fixes](/docs/running/game-fixes/) has the settings to change once you know more.

## System check

Settings › [System check](/docs/settings/system-check/) runs every check Universe has. **Needs attention** lists the ones that fail, each with a **To fix:** line, and **A** installs what a row needs when an install fixes it. When Universe itself won't start, [`universe doctor`](/docs/reference/cli/doctor/) runs the same checks in a terminal.

## A game's logs

Press **Start** on the game › **Manage** › **Sessions and logs**, or during a game HOME › **Game** › **Sessions**. Each session says how it ended, and **A** (**Read the log**) shows its log, the launch command first.

The logs survive a reboot only when the system keeps its journal. System check's **Game logs kept across reboots** says whether it does.

## How a session ended

- **Quit**: the game exited normally.
- **Stopped**: you stopped it from Universe.
- **Crashed (exit 1)**: it exited with an error, here code 1. **Crashed** alone means Proton filed a crash report.
- **Killed**: a signal Universe didn't send ended it, such as the out-of-memory killer's.

A Proton game that crashed may still read **Quit** when Proton filed no report.

## Debug log

**Debug log**, off by default, has Proton, Wine and DXVK write their full logs for each session. They're large, so turn it on for a game that misbehaves and off again after. It's in the **Proton** card of the game's settings (**Logs** for a Wine game), behind **Y**. The game's **Data and saves** page shows where the files go, under **Storage** › **Logs**.

It also prints the installed version, as the game's files give it: a Windows program's version, a Unity game's own, a PS3 disc's, the update a Switch emulator applies or a ROM's name. When the files say nothing or the wrong thing, set **Installed version** in Game settings (Show advanced), or run `universe set <game> version.pin=1.2`.

## Prefix tools

A Windows game's prefix tools are on its **Data and saves** page (**Start** › **Manage** › **Data and saves**), under **Wine Prefix**:

- **Wine Configuration** opens winecfg.
- **Winetricks** installs runtimes and fonts.
- **Run a Program in the Prefix…** starts an installer or a tool there.
- **Stop the Prefix's Programs** ends everything running in the prefix.
- **Reset the Prefix…** backs up the game's saves, then trashes the prefix, and the next launch makes a fresh one. It's offered for a prefix Universe made that no other game shares.
