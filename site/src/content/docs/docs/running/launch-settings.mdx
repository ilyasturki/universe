Most launch settings have a default that every game shares, and a game can set its own value over it.

<Shot name="settings-game-defaults" />

## Where each one is set

- A game's **Game settings** open from its game menu, with **Start** on the game or **···** on its page. Its cards are **Display**, **Overlay**, the runner's card (**Proton** or **Wine**), **Launch** and **Desktop and library**, then one for each feature and store.
- Settings › [Game defaults](/docs/settings/game-defaults/) holds the defaults.
- The Proton and Wine defaults are on the runner's page, in Settings › **Emulators & Proton**.
- A runner's page sits in between for its **Gamescope** switch and an emulator's options: the game's value wins over the runner's, which wins over the default.

Some settings belong to one game only, such as **Arguments** or **Wine prefix**.

**Y** shows or hides the advanced rows. Every page opens with them hidden.

## How a row reads

A row the game sets itself reads **CHANGED**, with a bar along its left edge. A row it doesn't set names where its value comes from:

- **Default**, Universe's own default;
- **Global**, a default you set;
- **Runner**, the runner's page;
- **Found**, the program Universe found.

A value of `auto` shows what it comes to on this machine, as in "auto · 144" for the refresh rate on a 144 Hz screen.

## Reset, and every game at once

On a game's or a runner's page, **X** puts the row back to the value it inherits.

In a picker, **Y** applies the choice to **All games**, or to the set the row names, such as **All Proton games**. It becomes the default, and the games that set their own keep theirs.
