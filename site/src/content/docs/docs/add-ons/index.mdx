A module runs around a game session: it records the session, writes a journal entry once it ends, takes your screenshots, or sets up the emulator's pads. A store lists the games you own there and installs them. A theme is a look for Universe Big Screen. Add-ons are the modules, stores and themes other people make ([Installing add-ons](/docs/add-ons/installing/)).

Universe comes with four stores ([Settings › Stores](/docs/settings/stores/)), three looks ([Looks](/docs/using/looks/)) and five modules. Every module starts off:

- [Video capture](/docs/add-ons/video-capture/) records each session.
- [Play journal](/docs/add-ons/play-journal/) has a model write an entry about each session.
- [Screenshots](/docs/add-ons/screenshots/) takes the screenshots you ask for.
- [Virtual pads](/docs/add-ons/virtual-pads/) gives an emulator one virtual pad per player.
- [Emulator controls](/docs/controllers/emulator-controls/) writes each emulator's controller settings for the pads you hold.

## Settings › Features

<Shot name="settings-features" />

Settings › [Features](/docs/settings/features/) has one row per module. **A** opens its page and **Y** turns it on or off. Each row says where its module stands:

- **On** or **Off**.
- **Set it up**: it's on, but waits on a setting it can't guess. The line under it names the setting.
- **Unavailable**: a program it needs is missing, or it was written for another version of Universe. [System check](/docs/settings/system-check/) gives the fix.

## A module for one game

A module runs for a game when it's on in Features and on for that game, in the card named after it in the game's **Game settings**. It's on for every game at first. Emulator controls and Virtual pads serve emulated games alone; the other three serve every game.
