A Windows `.exe`, a Linux program, a ROM or a disc image goes into the library by hand. You pick the file, and Universe proposes the runner and the title.

## Adding a file

The last tile of the Library grid, **Add a game**, opens a page with **Pick a game file…**, a row per store and **Import from Lutris** ([Lutris and Heroic](/docs/library/lutris-heroic/)).

1. Press **A** on **Pick a game file…**, and choose the file in **Game file**.
2. Pick the **Runner** it starts through. The runners that open that kind of file come first.
3. Keep or change the **Title of the game**.

A runner's page in Settings › Emulators & Proton also ends its **Games** card on **Add a game…**, which skips the runner question.

Universe takes the folder holding a Windows game's `.exe` as its install folder. Add one from a folder of its own, not from a shared one such as Downloads: **Uninstall…** later moves that whole folder to the trash.

## Its artwork

A game you add by hand gets its art, description and screenshots the next time Universe starts. To fetch them now, open the game menu (**Start** on the game) › **Manage** › **Artwork**, then **Start** › **Fetch missing art**. Settings › **Artwork** fetches it for every game missing some ([Artwork](/docs/library/artwork/)).
