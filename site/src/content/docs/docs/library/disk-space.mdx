Universe moves none of a game's data by itself, and sends nothing to the trash unless you ask.

## What one game takes

A game's **Data and saves** page, from the game menu (**Start** on the game) › **Manage**, gives the size of its saves, backups, Wine prefix, install folder, recordings and logs.

The prefix row says whose prefix it is, and two rows act on it:

- **Move into Universe's Prefixes** moves a prefix another launcher made, such as Lutris, into **Windows game folders**.
- **Reset the Prefix…** backs up the saves, then moves the prefix to the trash. The next launch makes a fresh one.

## Every game at once

Settings › [Storage](/docs/settings/storage/) shows the size of Universe's folders and of every game, biggest first, then the **Leftovers**: prefixes no game uses, a removed game's recordings, logs and folder. **A** on a leftover moves it to the trash, after asking. Trashing a removed game's folder takes its hours with it.

## Uninstall or remove

An install folder is often the biggest part, and the two actions treat it differently:

- **Uninstall…** deletes the install and keeps the game in your library, with its hours, journal and recordings. A store game has it in its row's menu in Settings › Downloads, and a game you added by hand on its runner's page in Settings › Emulators & Proton.
- **Remove from library…** leaves the files where they are. A store game's install then shows in Settings › Downloads as **Not in your library**, where **Delete files…** removes it. A game you added by hand isn't listed anywhere after that, so uninstall it first.
