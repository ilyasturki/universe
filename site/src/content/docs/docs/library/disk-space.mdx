A game's data sits in up to seven places: its install folder, its Wine prefix, its saves, their backups, Universe's own folder for it (its settings, art, screenshots and journal), its recordings and its logs. Universe moves none of it by itself, and sends nothing to the trash unless you ask.

## What one game takes

A game's Data and saves page, from the game menu (**Start** on the game) › **Manage** › **Data and saves**, gives each part with its size. Its **Saves** and **Backups** sections hold the saves, **Wine Prefix** the prefix, and **Storage** the **Install folder**, **Universe's files** (artwork, screenshots and journal), **Recordings** and **Logs**.

The prefix row says whose prefix it is (**Universe's prefix**, **Steam's prefix**, **Lutris's prefix**, **Wine's default prefix** or **A prefix of its own**) and which other games share it. Two rows move or reset it:

- **Move into Universe's Prefixes**, for a Lutris prefix or one elsewhere, moves it into **Windows game folders**, and every game on it follows. Across drives it's a copy, which can take a while. The other launcher keeps pointing at the old path.
- **Reset the Prefix…**, for Universe's own prefix when no other game uses it, backs up the saves, then moves the prefix to the trash. The next launch makes a fresh one.

[`universe data`](/docs/reference/cli/data/) prints the same parts with their sizes, and its `move-prefix` and `reset-prefix` do the same two things.

## Every folder at once

Settings › **Storage** has three cards:

- **Folders**: Universe's folders, each with its size and the free space on its drive. They are Games, Windows game folders, Save backups, Recordings, Library data, Runners and tools, and Logs.
- **Games**: every game, biggest first, with its install, prefix, saves and recordings. **A** opens its Data and saves page.
- **Leftovers**: what no game holds any more, or **None**.

The sizes come from walking the folders, which takes a few seconds; **X** (**Refresh**) counts again. [`universe storage`](/docs/reference/cli/storage/) prints the same three tables.

## What no game holds any more

A leftover is a folder no game of your library uses:

- **Prefix no game uses**: a folder in Windows game folders that is no game's prefix;
- **Archived recordings**: the recordings of a game you removed;
- **Removed game**: Universe's folder for a game you removed, with its settings, its art and its sessions;
- **Removed game's logs**.

**A** on one asks first, and **Move to Trash** sends it there, where it stays until you empty the trash. Trashing a Removed game takes that game out of your library for good, its hours with it. From a terminal, `universe storage trash <path>` takes a path `universe storage` listed, and nothing else.

## Uninstall or remove

An install folder is never a leftover, and it's often the biggest part. Two actions treat it differently:

- **Uninstall…** deletes the install and keeps the game in your library with its hours, journal and recordings. A store game has it in its row's menu in Settings › Downloads, and a Windows game you added by hand in Settings › Emulators & Proton › its runner › **Games**.
- **Remove from library…** leaves the files where they are. A store game's install then shows in Settings › Downloads as **Not in your library**, where **Delete files…** removes it. A game you added by hand isn't listed anywhere after that, so uninstall a Windows one before you remove it.

[`universe rm`](/docs/reference/cli/rm/) with `--purge` also trashes the game's logs and, when it lies in Windows game folders, its prefix, after backing up the saves. It refuses a prefix another game uses.

## An install no library game uses

Under Settings › Downloads › **On this PC**, a store install that no game of your library stands for reads Not in your library. It may be one you removed from the library, one another launcher left behind, or one no scan has brought in. Delete files… in its menu asks first, then goes through the store's own uninstaller (Steam, Epic Games, itch.io) or moves the folder to the trash (GOG). A folder that a library game holds is refused.

From a terminal, [`universe uninstall`](/docs/reference/cli/uninstall/) does it with `--source` and the store's id for the game, which [`universe library`](/docs/reference/cli/library/) lists.

## In the other looks

The Switch 2 look has the storage view in System Settings › **Data Management**, and a game's data in its Software Options › **Data Management**. The PS5 look opens **Console Storage** from its Welcome hub, and a game's **Saved Data and Storage** from its options.
