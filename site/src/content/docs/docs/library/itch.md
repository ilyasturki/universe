Universe installs and updates what you own on itch.io, and takes over the games the itch app installed. The store is off until you press **Y** on **itch.io** in Settings › **Stores**.

## Signing in with an API key

1. On Settings › Stores › itch.io, pick **Get an API key**. It shows itch.io's API keys page as a QR code and as an address.
2. Generate a key there.
3. Pick **Enter the key** and enter it.

## Your itch.io games

Universe lists the games and tools you own, bought or claimed. A bundle's games show up once you've claimed them on itch.io.

Installing, updating and uninstalling work as for [every store](/docs/library/gog/#installing-from-the-store). Universe installs a full Linux or Windows build, Linux first; **Build to install when a game has both** changes that. A browser game has nothing to install.

The games the itch app installed show under **On this PC**, ready for **Add to library**, and stay where they are. The first run's **itch** row adds them all at once.

itch.io keeps no achievements or cloud saves.
