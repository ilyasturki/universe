GOG is the only store on at first. Every store installs from Settings › **Downloads**, so what this page says about installing and updates holds for all four; the [Steam](/docs/library/steam/), [Epic Games](/docs/library/epic/) and [itch.io](/docs/library/itch/) pages say what differs.

## Signing in

In Settings › **Stores**, **Y** turns a store on or off and **A** opens its page.

<Shot name="settings-stores" />

1. On Settings › Stores › **GOG**, pick **Get a sign-in link**. It shows a QR code and an address.
2. Open it on your phone or a computer, and sign in to GOG.
3. You land on an address ending in `code=…`. Pick **Enter the code** and enter what follows `code=`, or the whole address.

**Signed in** then shows your GOG user name.

## Installing from the store

A game you own joins your library once you install it. Settings › Downloads shows one store at a time, and its **Store** card picks another. **A** on a game opens what you can do with it, such as **Install**, **Update** or **Uninstall…**.

<Shot name="settings-downloads" />

**Install** asks first, with the download size and the free space. One install runs at a time. Cancelling keeps what was downloaded, and **Resume** picks it up. **X** (**Refresh**) asks the store again, so a game you just bought shows up.

New games go in the folder the first run asked for, `~/Games` by default. Settings › **Game defaults** › **Folders** › **Games**, shown with **Y**, changes it for every game installed from then on.

## Games already on this PC

A GOG game already on this PC shows under **On this PC** as **Not in your library**, and **Add to library** brings it in with its art. The first run's **Heroic · GOG** row adds them all at once.

## Updates

Universe never updates a game by itself. A game behind reads **Update available**, and Downloads in the sidebar counts them. **Update** updates one game, **Update everything** all of them.

## Uninstalling

**Uninstall…**, in the game's menu in Settings › Downloads, moves its folder to the trash and keeps the game in your library, ready to install again. [Disk space](/docs/library/disk-space/#uninstall-or-remove) says how it differs from removing the game.

## Cloud saves and achievements

GOG's page in Settings › Stores turns both on or off for every GOG game, and a game's **Game settings** › **GOG** card for that game alone. **Achievements** is on, and needs comet: System check says when it's missing. [Cloud saves](/docs/library/saves/#cloud-saves) are off.

## GOG's settings

**Depot platform** picks the build GOG downloads: **Windows**, the default, or **Linux**. Give a Linux build the Linux runner, in its Game settings › **Launch** › **Runner**. **Install owned DLCs** is on by default.

The Switch 2 and PS5 looks install from other pages: see [Looks](/docs/using/looks/).
