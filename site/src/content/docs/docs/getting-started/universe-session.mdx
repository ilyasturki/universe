The Universe session is an entry on your login screen, next to GNOME or Plasma. Log in to it and Universe Big Screen takes the whole screen inside its own gamescope, with no desktop behind it, the way SteamOS runs Steam in Game Mode. It needs gamescope.

## Adding it to the login screen

- The Arch and Fedora packages install it.
- The [installer](/docs/getting-started/install/#steamos-bazzite-and-other-distributions) adds it through sudo, as `/usr/share/wayland-sessions/universe.desktop`. Where `/usr` is read-only, as on SteamOS and Bazzite, it goes under `/usr/local/share/wayland-sessions` instead, which GDM and SDDM read and LightDM doesn't. Without sudo, the installer prints the command to run as root.
- On NixOS, set `programs.universe.session.enable`. It needs `programs.universe.enable`, which brings the session's gamescope.

Then pick **Universe** in the login screen's session menu. To boot straight into it on NixOS, make it the default session and log in automatically:

```nix
programs.universe.enable = true;
programs.universe.session.enable = true;
services.displayManager.defaultSession = "universe";
services.displayManager.autoLogin.user = "alice"; # your user name
```

The session's gamescope follows your global gamescope settings, HDR included ([Gamescope, HDR and frame rate](/docs/running/gamescope/)).

## Inside the session

The startup animation plays once, at login. From there it's the Universe Big Screen you know from the desktop, **HOME** and the dock over a game included, with these differences.

### Logging out

Hold **B** for the power menu, or open it from the power button in the top bar or Settings › About › **Power**. In the session its first item reads **Log out** instead of **Quit Universe**, and it takes you back to the login screen. **Suspend**, **Reboot** and **Power off** follow when logind allows them.

There's no lock screen. Waking the machine from suspend lands on the launcher, as does an automatic login at boot.

### Network and Bluetooth

Settings › [Network](/docs/settings/network/) joins Wi-Fi networks, and Settings › [Bluetooth](/docs/settings/bluetooth/) pairs controllers, keyboards and headphones.

:::note
Universe doesn't set up WEP or WPA Enterprise networks. Join one of those once from a desktop session, and the session can connect to it from then on.
:::

Your first controller comes by USB cable, or use a keyboard, since pairing over Bluetooth needs something to drive Settings with. A DualSense or DualShock 4 plugged in by cable [pairs there and then](/docs/controllers/bluetooth/#pairing-a-dualsense-or-dualshock-4-by-cable).

### System tools

Nothing in the session can ask for a password. gamescope, MangoHud and gpu-screen-recorder still install from inside it, from Settings › Emulators & Proton › **Tools** or a System check row, through a helper the packages and the installer put in place for those three programs alone. If the installer ran without sudo, the helper is missing and those rows can't install. The helper goes through PackageKit, so where PackageKit can't install one (on NixOS, on an image-based system, or where the distribution doesn't package it), the rows show the fix to apply yourself.

## When it can't start

The login screen comes back:

- at once when gamescope isn't installed;
- when gamescope quits before the launcher comes up, or shows nothing for 30 seconds;
- when the launcher crashes five times in a row, each time within a minute of starting. A single crash only restarts it, without the startup animation.

To find out why, log in to a desktop session and run [`universe doctor`](/docs/reference/cli/doctor/), or open Settings › System check. Its **Gamescope** line says whether gamescope is there.

## In the other looks

The Switch 2 look's **Power Options** and the PS5 look's power menu say **Log Out**. The PS5 Control Center's Power panel has a **Log Out** of its own.
