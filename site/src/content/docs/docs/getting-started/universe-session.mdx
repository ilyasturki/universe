The Universe session is an entry on your login screen, next to GNOME or Plasma. Log in to it and Universe Big Screen takes the whole screen, with no desktop behind it, the way SteamOS runs Steam in Game Mode. It needs gamescope.

## Adding it to the login screen

The Arch and Fedora packages and the installer add it. On NixOS, set `programs.universe.session.enable`. Then pick **Universe** in your login screen's session menu.

To boot straight into it on NixOS, make it the default session and log in automatically:

```nix
programs.universe.enable = true;
programs.universe.session.enable = true;
services.displayManager.defaultSession = "universe";
services.displayManager.autoLogin.user = "alice"; # your user name
```

## Inside the session

It's the Universe Big Screen you know, **HOME** and the dock over a game included. The power menu (hold **B**) starts with **Log out**, which takes you back to the login screen.

<Shot name="power-menu" />

There's no lock screen: waking the machine from suspend lands on Universe.

Settings › [Network](/docs/settings/network/) joins Wi-Fi, and Settings › [Bluetooth](/docs/settings/bluetooth/) pairs controllers and headphones. Plug your first controller in by cable, or use a keyboard, to reach those pages. A DualSense or DualShock 4 plugged in by cable [pairs there and then](/docs/controllers/bluetooth/#pairing-a-dualsense-or-dualshock-4-by-cable).

Nothing in the session can ask for a password, yet gamescope, MangoHud and gpu-screen-recorder still install from Settings › Emulators & Proton › **Tools**. Where your system can't install one that way, the row shows what to do.

## When it can't start

The login screen comes back when gamescope is missing or fails to start, or when Universe keeps crashing. Log in to a desktop session and open Settings › [System check](/docs/settings/system-check/) to see why.

The Switch 2 and PS5 looks name some of this differently: see [Looks](/docs/using/looks/).
