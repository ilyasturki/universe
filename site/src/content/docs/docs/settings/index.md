title: Settings
description: How Settings is laid out, how to move through it, and what each of its sections holds.
---

Settings is the last tab of the Universe look. Its sections sit in a sidebar under four groups, and the focused section's cards fill the rest of the screen.

## Moving around

- In the sidebar, Up and Down switch the section. **A** or Right goes into its cards, **B** back up to the tab bar.
- In the cards, **A** acts on the focused row: it flips a switch, runs an action or opens a choice. **B** returns to the sidebar.
- **X** refreshes the sections that read from the system: Downloads, Emulators & Proton, Controller, Sound, Performance, Storage and System check. On an environment variable in Game defaults, it removes the variable.
- **Y** turns the focused store or feature on or off without opening it, and shows or hides the advanced rows of Game defaults.
- **Start** opens More, a menu of the same actions.
- **LT** and **RT** step through the sections from anywhere on the page.

The hint bar shows which keys the focused row takes, and its description sits under the cards. A number on a sidebar entry counts what waits there: store updates on Downloads, builds to update or install on Emulators & Proton.

## Finding a setting

Search, the magnifier in the tab bar, finds a section by its name or what it holds, and the rows of Game defaults, Controller, the runners, the stores and the features, down to each game's own settings. Opening a result lands on its row. The former section names still work: Launch, Runners, Sources, Install, Modules, Themes, System and Doctor find Game defaults, Emulators & Proton, Stores, Downloads, Features, Appearance, Performance and System check.

## The sections

Games:

- [Stores](/docs/settings/stores/): which stores are on, signing in, and each store's settings.
- [Downloads](/docs/settings/downloads/): installs, updates, and the games each store has on this PC.
- [Controller](/docs/settings/controller/): the controller in your hands, its buttons, the button test and setup.
- [Game defaults](/docs/settings/game-defaults/): what every game starts from, before its own settings.
- [Emulators & Proton](/docs/settings/emulators-proton/): the runners and tools, installed, updated and rolled back.

Extras:

- [Features](/docs/settings/features/): the optional modules, and add-ons others made.
- [Artwork](/docs/settings/artwork/): the art each game has, and what it lacks.
- [Appearance](/docs/settings/appearance/): the look, its sounds and the startup animation.

System:

- [Network](/docs/settings/network/): Wi-Fi.
- [Bluetooth](/docs/settings/bluetooth/): controllers, headphones and keyboards without a cable.
- [Sound](/docs/settings/sound/): where the sound plays.
- [Performance](/docs/settings/performance/): brightness, a Steam Deck's refresh rate, the power limit, the GPU clock and SteamOS's fan curve.
- [Storage](/docs/settings/storage/): what Universe's folders and each game take on disk.

Universe:

- [System check](/docs/settings/system-check/): what Universe needs from the system, and how to fix what's missing.
- [About](/docs/settings/about/): the version, What's new, first-run setup and the power menu.

## Sections that hide

Under Steam's Game Mode, Sound, Network, Bluetooth and Performance hide. Elsewhere:

- Performance needs a control Universe can set; its page lists them.
- Network needs NetworkManager and a Wi-Fi device. A cable needs nothing set up.
- Bluetooth needs a Bluetooth adapter.

## In the other looks

The Switch 2 and PS5 looks keep the same four groups, with a few sections named or placed differently:

| Universe | Switch 2 | PS5 |
| --- | --- | --- |
| The tab bar's search | Search | Search Settings |
| Downloads | Updates | Updates |
| Controller | Controllers | Controllers |
| Game defaults | Game defaults | Game Defaults |
| Artwork | (a game's own Artwork page only) | Artwork |
| Network | Internet | Network |
| Bluetooth | Bluetooth | Accessories |
| Storage | Data Management | (the Console Storage tile on the Welcome hub) |
| System check | System check | System Check |

The Switch 2 look opens Settings from HOME's **System Settings** button, the PS5 look from the **Settings** icon in its top bar.

Universe Desktop keeps the settings you'd change with a mouse in **Preferences** (<kbd>Ctrl</kbd>+<kbd>,</kbd>): Stores, Controller, Game Defaults, Emulators & Proton, Features, and Performance on a Steam Deck. Its main menu opens Library Artwork, System Check, Storage and What's New.
