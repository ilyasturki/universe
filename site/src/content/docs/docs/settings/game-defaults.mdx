Settings › **Game defaults** holds the values every game takes until its own Game settings change them ([Launch settings](/docs/running/launch-settings/)). **Y** adds the advanced rows and cards.

<Shot name="settings-game-defaults" />

## Display

- **Gamescope**, on: games run inside gamescope.
- **Resolution**, **Refresh rate** and **Adaptive sync**, on auto, follow the screen.
- Behind **Y**: **Scaler**, **Filter**, **Sharpness**, **Gamescope arguments** and **Discrete GPU**.

[Gamescope, HDR and frame rate](/docs/running/gamescope/) explains each one.

## Overlay

- **Show MangoHud**, off.
- **Frame rate limit**, on auto: the refresh rate the game sees.
- **Pause on HOME**, on: the game freezes while Universe covers it.
- **Hide the cursor while playing**, on.
- **Keep the screen awake**, on: no blanking or automatic suspend during a game.

## Saves and updates

- **Back up after playing**, on, and behind **Y**, **Backups kept**, 5 ([Saves](/docs/library/saves/)).
- **Show what's new after an update**, on, the same switch as in Settings › About.

## Behind Y

- **Environment**: the variables every game gets ([Environment variables](/docs/running/environment/)).
- **Programs**: the gamescope and umu-run programs Universe runs.
- **Folders**: **Games**, where stores install games, **Windows game folders**, **Save backups** and **Recordings**.
- **API keys**: the [SteamGridDB key](/docs/library/artwork/#steamgriddb).
- **Desktop**: the desktop Universe works with, found by itself on auto.
- **Proton builds**: names for Proton builds in folders of your own.

A picker's first choice, "Default · …", goes back to the default. The Proton and Wine defaults, such as **Proton build** and **HDR**, are on the runner's page in Settings › [Emulators & Proton](/docs/settings/emulators-proton/).
