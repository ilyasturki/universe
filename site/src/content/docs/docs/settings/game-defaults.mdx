Settings › **Game defaults** holds the values every game takes until its own Game settings change them ([Launch settings](/docs/running/launch-settings/)). **Y** adds the advanced rows and cards.

<Shot name="settings-game-defaults" />

## Display

**Gamescope**, on, runs games inside gamescope. **Resolution**, **Refresh rate** and **Adaptive sync**, on auto, follow the screen. [Gamescope, HDR and frame rate](/docs/running/gamescope/) explains these and the rows behind **Y**.

## Overlay

- **Show MangoHud**, off.
- **Frame rate limit**, on auto: the refresh rate the game sees.
- **Pause on HOME**, on: the game freezes while Universe covers it.
- **Hide the cursor while playing**, on.
- **Keep the screen awake**, on.

## Saves and updates

- **Back up after playing**, on, and behind **Y**, **Backups kept** ([Saves](/docs/library/saves/)).
- **Show what's new after an update**, on, the same switch as in Settings › About.

## Game updates

**Game updates** lists the games with a newer release out. **A** on a game its store updates installs the update. On a game you update yourself, such as a repack, install the update, then choose **I have the latest version**.

Behind **Y** are the games Universe can't check, because nothing tells it which build your files are. **A** shows your version and the newest release's date, then **It's the latest** takes the game as up to date, and Universe flags the next release.

A PC game is checked against Steam, so it needs its id: in its Game settings, **Desktop and library** › **Steam app id**, behind **Y**.

## Behind Y

**Y** adds **Environment** ([the variables every game gets](/docs/running/environment/)), **Programs**, **Folders**, **API keys** (the [SteamGridDB key](/docs/library/artwork/#steamgriddb)), **Desktop** and **Proton builds**.

A picker's first choice, "Default · …", goes back to the default.
