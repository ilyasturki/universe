Settings › **About** gives the version and each release's changes, runs the first-run setup again and opens the Power menu.

<Shot name="settings-about" />

- **Version**: the version number. **A** opens What's new.
- **What's new**: **A** (**Open**) shows every release's changes, newest first, with a screenshot or a clip for the main ones.
- **Show what's new after an update**: opens What's new once, the first time you start a new version. On by default.
- **First-run setup**: **A** (**Run again**) opens the [first-run setup](/docs/getting-started/first-run/).
- **Power**: **A** (**Open**) opens the [Power](/docs/using/getting-around/#power) menu, as holding **B** does.

Every release's notes are also in the [changelog](/docs/changelog/).

The Switch 2 and PS5 looks lay this section out differently: see [Looks](/docs/using/looks/).
