Settings › **Network** shows how the machine is connected and joins Wi-Fi networks. It shows only on a machine with Wi-Fi, and never under [Steam's Game Mode](/docs/getting-started/steam-deck/#steams-game-mode). A cable needs nothing set up.

- **Connection** reads **Cable**, the Wi-Fi network joined, or **Offline**, with how the internet answered last. **Test connection** asks again.
- **Wi-Fi** turns the machine's Wi-Fi on or off.
- **Networks** lists the networks in range, as long as the section is open. **A** (**Connect**) joins one, asking for its password, and **A** (**Forget**) on the network in use forgets it.

Universe doesn't set up WEP or WPA Enterprise networks. Join one once from a desktop, and Universe can join it from then on.

The Switch 2 look calls this section **Internet**: see [Looks](/docs/using/looks/).
