Settings › **Downloads** installs, updates and uninstalls store games, one store at a time. The sidebar entry counts the updates waiting.

<Shot name="settings-downloads" />

Its cards, the first three only when they have something in them:

1. **Store**, when two stores or more are on, picks another.
2. **Installing** holds the install or update running, and the paused ones.
3. **Updates** has **Update everything**, which updates the store's games one after another.
4. **On this PC** lists the store's games installed here, with their size.
5. **Not installed** lists the games you own that aren't installed.

A game's row reads **In your library**, **Not in your library**, **Update available**, **Owned**, **Installing…** or **Paused**. **A** (**Options**) opens its menu:

- **Cancel install**, which keeps the files and pauses it;
- **Install**, or **Resume** a paused one;
- **Update**, when one is waiting;
- **Add to library** and **Delete files…**, for an install no library game uses;
- **Play**, **Details**, **Game settings**, **Uninstall…** and **Remove from library…**, for a game in your library.

The actions that touch the disk ask first. **X** (**Refresh**) asks the store for its listing again.

[GOG](/docs/library/gog/#installing-from-the-store) explains installing, and [Disk space](/docs/library/disk-space/#uninstall-or-remove) how Uninstall and Remove differ.
