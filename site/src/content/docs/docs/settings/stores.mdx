Settings › **Stores** lists the stores Universe installs games from. Four come with Universe (Epic Games, GOG, itch.io and Steam), and a store add-on joins them once you install it. Each store has a page of its own for its settings and its sign-in.

## The list

The stores that are on come first, in a card with no title. The ones that are off follow in the **Off** card, and **Get more…** sits alone at the bottom.

Each row reads its state on the right:

- **On** or **Off**.
- **Set it up**: the store is on, but a setting it can't guess is still empty. The detail line names it ("On, waiting on …").
- **Unavailable**: a program the store needs is missing. The detail line reads "Cannot be enabled: missing …", or "On, but its hooks are skipped: missing …" when the store was already on.

Otherwise the detail line is the store's description. An add-on installed from outside the index is tagged **Unlisted**.

A new configuration has GOG on and the other three off (`[sources] enabled = ["gog"]` in config.toml).

**Get more…** ("Add-ons: stores others made") opens the **Add-ons** menu, which lists the stores in the add-on index. [Installing add-ons](/docs/add-ons/installing/) covers what it offers.

## Keys

- **A** opens the focused store's page.
- **Y** (**Enable** or **Disable**) turns the store on or off without opening it. The row moves to its new card and the cursor goes with it. Y is dimmed on a store that is off and unavailable.
- **Start** opens **More**, with the same Enable or Disable.

## A store's page

The header reads SOURCE over the store's name. Under it come an add-on's version and origin ("v1.2.0 · from the index") or a warning in red, then the store's description. The page's cards are listed down its left side:

- **Settings** starts with **Enabled**. While the store is off, that switch is the only row, and it's greyed out when the store can't be turned on. Once the store is on, its own settings follow, the advanced ones hidden until you press **Y** (or **Start** › **Show advanced**). Turning on a store that waits on a setting puts the cursor on that setting.
- **Game defaults** sets the store's per-game settings for all of its games at once, until a game sets its own in its Game settings. This card is the store's own; the [Game defaults](/docs/settings/game-defaults/) section of Settings is a different page.
- **Sign-in** holds **Signed in**, whose detail is the account name; **Get a sign-in link**, or **Get an API key** for a store that signs in with a key; and **Enter the code** or **Enter the key**. A sign-in link comes up in a **Sign-in link** card with a QR code to scan from your phone, the address and what to do with it.

On these cards, a picker's first choice, "Default · …", puts the store's default back.

The built-in stores' rows:

| Store | Settings | Behind Y | Game defaults | Sign-in |
| --- | --- | --- | --- | --- |
| Epic Games | Install folder, Install owned DLCs | Anti-cheat runtimes, legendary's folder, Adopt installs from, Install time limit | Achievements, Cloud saves | a code |
| GOG | Install folder, Depot platform, Install owned DLCs | Scanned folders, gogdl token file, Install time limit | Achievements, Cloud saves | a code |
| itch.io | Install folder, Build to install when a game has both | butler's database, Adopt installs from, Install time limit | none | an API key |
| Steam | Share Steam's prefix | Steam's folder, Install confirm time, Install time limit | Achievements | an API key |

## From the command line

A store's settings live in config.toml under `[sources.<id>]` (the ids are `epic`, `gog`, `itch` and `steam`), and a game's own values in its `game.toml`.

- [`universe source`](/docs/reference/cli/source/) does what this section does with `ls`, `enable <id>`, `disable <id>`, `settings <id>` and `set <id> key=value`, which takes `--game <game>` for one game's value.
- [`universe sources`](/docs/reference/cli/sources/) prints each store's state and install folder.
- [`universe login`](/docs/reference/cli/login/) `<store>` prints the sign-in link, then takes the code.

The pages for [GOG](/docs/library/gog/), [Steam](/docs/library/steam/), [Epic Games](/docs/library/epic/) and [itch.io](/docs/library/itch/) explain each store's settings and sign-in.

## In the other looks

The Switch 2 look has the same list under System Settings › **Stores**, and the PS5 look under Settings › **Stores**. Both turn a store on or off with **X**. Universe Desktop has it in Preferences › **Stores**.
