Settings › **Features** turns on and sets up the optional features that run around each game session: **Video capture**, **Emulator controls**, **Play journal**, **Virtual pads** and **Screenshots**. Each one starts off.

<Shot name="settings-features" />

The features that are on come first, then the **Off** card, then **Get more…** for [add-ons](/docs/add-ons/installing/). Each row reads its state ([Add-ons and modules](/docs/add-ons/)).

- **A** opens the feature's page.
- **Y** turns the focused feature on or off in place.

A feature's page starts with **Enabled**. Once it's on, its settings follow, the advanced ones behind **Y**. Its **Game defaults** card sets its per-game settings for every game, until a game sets its own in its **Game settings**.

Each feature's own page has its settings: [Video capture](/docs/add-ons/video-capture/), [Emulator controls](/docs/controllers/emulator-controls/), [Play journal](/docs/add-ons/play-journal/), [Virtual pads](/docs/add-ons/virtual-pads/) and [Screenshots](/docs/add-ons/screenshots/).

The Switch 2 and PS5 looks turn a feature on or off with **X**: see [Looks](/docs/using/looks/).
