Settings › **System check** runs Universe's checks on this machine and says how to fix what fails. It checks the core, the runners, the media tools, the controller, and each feature and store that is on.

<Shot name="settings-system-check" />

Above the cards, two counts give the checks that pass and the ones that need attention.

**Needs attention** comes first when a check fails. Each row names the check, says what's wrong and gives a **To fix:** line. When an install fixes it, **A** (**Install**) installs the build or tool, after asking.

Then one card per area, **Core**, **Runners**, **Media**, **Controller** and the features and stores that are on, lists the checks that pass.

**X** (**Refresh**) runs the checks again. [Troubleshooting](/docs/running/troubleshooting/) covers what to do when a game won't start.
