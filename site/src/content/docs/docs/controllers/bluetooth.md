Settings › [Bluetooth](/docs/settings/bluetooth/) pairs pads, headphones and keyboards. It shows when the machine has a Bluetooth adapter, and never in Steam's Game Mode.

## Pair a controller

1. With no pad connected yet, plug one in by USB to get around the page.
2. Hold the pairing button of the pad you're pairing until its light blinks: SYNC on a Switch Pro, PS and Create together on a DualSense, the pair button on an Xbox pad.
3. Open Settings › Bluetooth and wait for the pad under **Found**.
4. Press **A** on it (**Pair**). Universe pairs it and connects it, and it reconnects by itself from then on.

**A** on a paired device offers **Connect** or **Disconnect**, and **Forget**.

## Pairing questions

Some devices ask a question while they pair:

- A code to confirm: pick **Pair** if the device shows the same code.
- A request to connect: pick **Pair** or **Cancel**.
- A passkey or a PIN: type the one the device shows, or its PIN, often 0000 or 1234.
- A code to type on the device: type it there, then press Enter on it.

A question that comes while a game holds the screen is refused. Pair the device again from HOME.

## Pairing a DualSense or DualShock 4 by cable

In the [Universe session](/docs/getting-started/universe-session/), a DualSense or DualShock 4 plugged in by USB can pair over the cable. Universe asks `Pair <name>?`, and after **Pair** the pad connects without the cable. On a desktop, the desktop asks instead.

When a paired pad stops answering in a game, reconnect it from the dock's [Controllers](/docs/using/playing/#controllers) button.
